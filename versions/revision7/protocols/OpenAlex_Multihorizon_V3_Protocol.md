# OpenAlex multi-horizon evaluation — pre-execution V3 protocol

**Status:** Proposed, complete design specification; **no V3 observations or provider calls were made to prepare this document**. The protocol must be frozen, code-versioned, and externally audited against frozen data before the first scored V3 run. V3 is a development/follow-up study informed by the Gemini V1 graph-visibility failure; it is **not** an independent held-out or human-judged evaluation. Use the verified graph-visible Terra V2 engineering implementation, not the original graph-packing code. The 585-request V1 graph audit showed summaries 585/585, graph candidates 436/585, explicit edges 0/585. V1 remains immutable.

## 0. The outcome we need

Do not equate maximum allowed actions with long-horizon work. Report (a) permitted actions, (b) *actual substantive retrieval/inspection/graph actions*, (c) research phases completed, (d) total provider calls, (e) evidence volume exposed, (f) source facts or edges actually present in later model inputs, and (g) context displacement. Long-horizon claims require measured sustained work or sustained evidence exposure. It is valid for a method to fail, stop, degrade, or cost more.

### Five architectures

| Code | Scholarly retrieval | Explicit verified graph memory | CLM-inspired model-controlled context editing |
|---|---|---|---|
| `standard` | Same frozen corpus and permitted data, non-LLM baseline | No | No |
| `llm` | Terra agent | No | No |
| `llm_graph` | Terra agent | Yes | No |
| `clm` | Terra agent | No | Yes |
| `clm_graph` | Terra agent | Yes | Yes |

All four hosted arms use exactly the same pinned Terra provider, inference profile, action/tool interface, base context budgets, task/question text, source corpus, evaluation rules and allowed information exposure. Graph arms only materialize relationships **legitimately acquired** during research, not hidden target witnesses. For short/long autonomous tasks, the standard baseline remains a useful nonagentic reference but must be transparently assessed under its actual retrieval/inspection allowances; a non-LLM script does not become a context-editing arm. In controlled memory pressure, only the four hosted arms are factorially comparable.

## 1. Study S: Short, natural-stop scholarly retrieval

- **Question:** In a small retrieval window, how do graph memory and CLM affect objective target discovery, verified citation-path acquisition, failure and efficiency?
- **Cases:** The original 30 frozen questions (six disciplines, five tasks/discipline), not chosen by V1 performance.
- **Matrix:** 30 tasks × 5 methods × 2 independent execution repetitions × **3-action cap** = **300 cells**. Prespecify replication seeds/trial labels and deterministic scheduling; the hosted provider may not honor a numerical seed.
- **Behavior:** No minimum action count. Allow valid early STOP. STOP is a measured result, and premature STOP on an incomplete question is a failure/limited-success observation, not a reason for ad hoc retries.
- **Metrics:** Known-target Recall@10 (benchmark targets only; not general relevance), verified citation-chain completion, per-task objective evidence acquired, response/metadata fidelity when objectively checkable, failure rate, actual actions, model calls, input/output tokens, cost and wall time.
- **Original 10-action horizon:** Optional **secondary diagnostic** (30 × 5 × 1 = +150 cells) only if its purpose is clearly specified; the V1 pilot showed that merely allowing 10 actions often did not cause 10-action work. Do not replace sustained-work studies with another upper-bound-only benchmark.
- **Comparison:** Four hosted arms form the factorial 2×2 comparison; standard is an external nonagentic reference.

## 2. Study L: Staged autonomous long-horizon scholarly investigation

- **Question:** Do memory mechanisms improve **ongoing multi-stage scholarly discovery and evidence carryover** when research objectives evolve across a sustained trajectory?
- **Cases:** **24 new auditable objective-development tasks**, exactly four per each of six frozen scholarly domains. These should be drawn by deterministic, outcome-blind candidate selection from the same frozen 30,000-work corpus. Avoid reused main-task targets and the six pilot questions where feasible. Reject a task before inference only for documented oracle infeasibility, data corruption, leakage, or non-uniqueness; keep an immutable candidate/rejection log.
- **Matrix:** 24 tasks × 5 methods × 2 repetitions = **240 cells**. No extra repetitions counted as independent tasks.
- **Task construction:** Each task is a *connected but nontrivial scholarly research project* with two distinct method/topic branches, multiple independently discoverable evidence papers, and verifiable directed citation paths. Each source/edge that counts toward outcomes must be accessible under the permitted tools and fixed corpus. Use oracle checks to confirm feasibility, **not** to supply an answer to agents. Balance task domains, target frequency, citation-path depth, and lexical difficulty as far as feasible; document residual imbalance.
- **Six required research phases:** All six phases and their next-stage instructions are frozen in advance and released sequentially to every arm. The harness advances to the next phase **without resetting the agent's accumulated state**. Every method receives the same newly revealed objective at the same logical point, with only the normal mechanism differences.
  1. **Scope and initial literature discovery:** identify a seed literature cluster using the common tools.
  2. **Investigate branch A:** locate and inspect primary research evidence for one methodological branch.
  3. **Investigate branch B:** locate and inspect a distinct but relevant methodological branch.
  4. **Citation-path investigation:** obtain verifiable paper-to-paper connections spanning the branches (at least one directed multi-hop relation in a feasible case).
  5. **Cross-study verification:** inspect support for competing or differing claims/methods and revisit previously collected evidence; explicitly distinguish unknown claims from verified metadata.
  6. **Evidence audit and research synthesis:** identify source-backed conclusions, unresolved items, and canonical provenance without generating unsupported claims.
- **Action budget:** Up to **six substantive scholarly tool actions per phase** (36 over six phases) and an separately tracked, identical global model-call ceiling for hosted arms; the final per-phase response allowance must be pinned before main runs. An action is a valid search/inspect/citation-expand/graph-query/recovery operation under the common action contract, not a null edit, redundant ping, or repeated refusal. Model-controlled CLM edits count against the prespecified comparable decision/call limit, but record them separately from scholarly-tool actions. Do **not** require 36 actions or reward unnecessary calls.
- **STOP semantics:** A STOP ends the **current phase**, not the entire six-phase project. Record early STOP, incomplete phase, stalled decisions and failed objectives. The harness then presents the next fixed research phase with preserved state. Do not override a safety refusal or perform fabricated retrievals. This makes the task truly extended without pretending an agent voluntarily researched for 36 actions.
- **Sustained-work criterion:** During **disjoint pre-main pilots**, verify that the staged task design really causes multiple meaningful retrieval/inspection activities, revisits earlier evidence, and creates measurable context competition or eviction. Record actual action count and phase count. If most pilots collapse to one or two substantive actions per phase or never cause any displacement, redesign task difficulty or evidence-delivery before freezing main cases; do not change cases after observing comparative main scores. During main evaluation never silently discard tasks where an agent stops early.
- **Primary endpoint:** **Per-task objective evidence completion score**: arithmetic mean of prespecified binary checks for distinct required source discoveries and verified directed citation links (with each case's item denominator and weighting fixed before inference). No model-written prose judged automatically as scientifically true. Report the exact target composition (IDs/edges) and permit only genuinely discovered items to score.
- **Secondary:** Completion of all six phase objectives; delayed recovery of early source ID/year/edge in a later phase; independently verified citation path discovery; early-stop rate by phase; source/evidence re-access; erroneous citation direction; working-context availability of gold evidence; input graph-edge exposure; meaningful actions, calls, tokens, wall time, cost, failures.
- **Fairness:** The nonagentic baseline may execute a pinned phase-by-phase retrieval script with the same phase disclosures and corpus and no target oracle, so it can be evaluated on evidence completion even without LLM context. Keep its observed-work advantage/disadvantage explicit.
- **Crucial limitation:** This is **staged autonomous research under externally released objectives**, not fully unconstrained autonomy or a human-crafted qualitative literature-review benchmark. State this in reporting.

## 3. Study M: Controlled 96-paper memory-degradation and recovery

This is the **extension** of `OpenAlex_Controlled_Memory_Benchmark_V2_Protocol.md`, not an unrelated benchmark runner.

- **Question:** As scholarly evidence exposure grows, do graph memory and CLM preserve or recover **actually seen** early source facts and citation links?
- **Cases:** **12 distinct objective research cases** (two per discipline), disjoint from the main short/long cases where practical. Build all cases from the same frozen corpus using deterministic offline feasibility checks and a hidden manifest. Each case contains **96 distinct legitimate scholarly papers** organized in **32 batches of three**. Include a verified citation-connected early cluster whose gold facts/relations remain fixed; the remaining papers are genuine domain-matched distractors and additional legitimate discoveries, not repeated answer passages.
- **Matrix:** 12 tasks × **4 hosted arms** × **2 repetitions** = **96 continuous exposure trajectories**. A single trajectory has four score checkpoints; these are not four independent trajectories.
- **Checkpoints:** after 24, 48, 72, and 96 papers. Use a frozen, identical *post-exposure snapshot* at each checkpoint. From that state fork two scoring branches:
  - **A (primary):** answer fixed delayed identity/year/directed citation questions using only material already in the active model context, with outside search, archive lookups and extra context edits disabled during the answer. The graph content included in that frozen selected context is fair game; do not append new graph evidence just for the quiz.
  - **B (secondary):** start from the **same saved state**, grant a fixed common budget of two archive/reopen/graph-query recoveries among **previously exposed records**, and answer the same questions. Count every call, including edits/recovery, consistently. Never carry either quiz answer or recovery result into the continuing main exposure trajectory.
- **Six fixed question roles:** early source ID from a distinctive excerpt, early source publication year, midstream source ID, directed one-hop citation, oriented two-hop chain, and evidence-calibration `SUPPORTED` versus `NOT_ESTABLISHED`. The first five produce objective binary exact-match scores; the sixth is a separately reported calibration outcome. Reuse exactly the same target facts/edges at all checkpoints to measure their decay, and **do not reintroduce answers in later distractor batches**. If a target cannot validly be queried at the first 24-paper checkpoint, the case must be rejected during pre-main construction.
- **Primary endpoint:** Average first-five-question exact accuracy at **96 papers, branch A, no recovery** for the four-arm factorial. This isolates end-state evidence usability. The branch A accuracy curve across 24/48/72/96 is a prespecified secondary endpoint; each case is the independent statistical unit. The four checkpoints permit mechanism trajectories, not four independent samples.
- **Other metrics:** Branch B recovery accuracy and uplift; factual IDs/years versus relation/path accuracy; original exposure success; archive availability; graph edges legitimately acquired, selected and actually delivered; active-context eviction, CLM edits, recoveries; calibration and unknown recognition; calls/tokens/latency/cost/failures. A paper is not considered exposed unless it was actually delivered in the arm's model input at least once.
- **Common capacity:** Same active/full token and character ceilings for all four arms, and same physical source stream. Preserve and measure context competition and any capacity admission rejects; never silently grant the graph arms more context. All arms must have equal access to the original source-reference facts. Only graph arms materialize indexed relationship structure; only CLM arms can model-edit their context.
- **Stopped agents:** A STOP choice is recorded but does **not** halt the *external* evidence schedule. This is controlled exposure, not free-choice retrieval; explicitly label it as such. The model may choose no-op maintenance while evidence continues. Do not let one architecture silently skip exposure while others receive it.
- **Pilot readiness:** Use disjoint unscored pilot cases and frozen packing limits to check actual exposure, context displacement, successful snapshot-forking and provider-call feasibility. Verify memory pressure **without inspecting relative accuracy outcomes**; if pressure is absent, adjust exposure richness/capacity uniformly and freeze before any scored main cases. Do not tune model prompts or case difficulty to favor any arm.

## 4. Causal interpretation, measurement and statistical plan

**All studies:** Save every cell's planned/completed/failed/missing state and predefine ITT operational failure scoring (failed final = zero if attempt made, never-run = missing); also report complete-case and failure-sensitivity estimates. Use one immutable read-only corpus snapshot, source hashes, actual request hashes and provider response identifiers, action receipts and per-stage provenance. Instrument graph pipeline `stored -> eligible -> selected -> packed -> transmitted -> later consumed/acted-upon` and CLM `proposed -> accepted -> committed -> in later request -> recovered`. Delivered-edge counts establish *exposure*, **not** causal reliance.

**Factorial 2×2 among hosted architectures:** Let `L`, `G`, `C`, `GC` be task-level scores for no-memory, graph-only, CLM-only, and combined. Graph effect `0.5[(G-L)+(GC-C)]`; CLM effect `0.5[(C-L)+(GC-G)]`; interaction `GC-G-C+L`. Calculate these from **within-task matched observations** with identical repetitions, task and experimental condition, not unmatched method averages. Report pairwise contrasts and negative effects. Paired task-level bootstrap stratified by discipline and prespecified task-level randomization/sensitivity analysis as applicable; multiple-test correction for the preregistered three primary factorial contrasts **per study**, with across-study multiplicity addressed transparently. Domains are fixed. Never treat repetitions, phase checks, papers, checkpoint observations or quiz items as independent tasks. A zero-width empirical bootstrap CI on six tasks is not proof of equivalence.

**Metric definitions:** Short = target-only Recall@10 (not general relevance); staged long = preregistered objective evidence completion; controlled memory = delayed exact answer accuracy under identical exposure and no recovery. Report separate panels, never average them into a fake universal score. Citation-year/quote-string checks do **not** establish semantic factual accuracy or hallucination reduction without independent claim adjudication.

**Task/pilot leakage:** Freeze test task manifests, gold item keys, citation relation witnesses, task ordering, model settings, source hashes, scoring and all objective criteria before the first scored run. Never include target work IDs/answer keys in action prompts, selectors or memory packing. V3 is explicitly post-diagnostic follow-up, because V1 results informed graph-packing repair. New target cases are not independently held-out human judgments by default.

**Presentation/reporting:** Three panels: S short retrieval effectiveness and efficiency; L actual research progress as phase index increases; M controlled delayed retention/recovery versus papers seen (24,48,72,96). Add graph actual input exposure (% of opportunities with eligible edges delivered), CLM edit/recovery rates, failure rates and absolute efficiency tradeoffs. Include 2×2 effect plots and task-clustered uncertainty for each study. Clearly distinguish measured provider latency from artificial task-stage time.

## 5. Operational plan, precedence and runtime

**First do offline engineering** using frozen real citations and mocked provider boundary: explicit directed edges reach the actual transmitted-input serialization; graph-only and graph+CLM receive equivalent eligible edges; CLM can preserve/recover real graph evidence; negative/no-edge cases; context packing remains within common bounds; strict answer/provenance validation; state snapshots and fork isolation; no cross-task or hidden-key leakage. The existing Gemini V1 campaign and all receipts remain read-only.

**Then a disjoint unscored pilot** for every study with the five/four arms as applicable, including a 96-paper pilot with checkpoints and a six-phase staged pilot. Pilot evaluates actual sustained actions, context pressure, costs/calls and correct instrumentation, not whether Graph+CLM wins. Freeze V3 protocol before scored trials.

**Core launch order** (complete matched blocks rotated across disciplines and arms within each study):
1. Study S: 300 cells (short fallback results package).
2. Study L: 240 cells (the main **long-horizon agent behavior** evidence, including recorded early stops by phase).
3. Study M: 96 exposure trajectories (the **long-context memory** evidence, with four correlated checkpoints and two independent scoring branches from each snapshot).
**Core total: 636 planned trajectories**, excluding disjoint pilots, probe branches and optional 10-action secondary test. This count does NOT mean 636 provider calls: Study L and Study M can involve many calls per trajectory. Implement automatic scientifically valid matched snapshots after each complete task block, and results export immediately after each study. If the primary goal is long-horizon coverage under a deadline, freeze Study S promptly and prioritize completed matched Study L blocks rather than launching optional short reruns.

**Money and authority:** This document intentionally does **not** optimize study design around the earlier $68 limit; the user requested a scientific-design thought experiment ignoring cost. This is **not new authorization to exceed the previous $68 hard provider limit** or to purchase credits. Keep the existing authorization until the user explicitly sets a new numeric maximum for actual execution. The engineering prompt must not make inference calls. The paid-run prompt must check genuine provider access, a single durable ledger, a revised explicitly authorized ceiling and stopping conditions before running anything.

**Eligibility to describe as long-horizon:** `L` has six substantive research phases and actual actions and source acquisition logged; `M` has 32 scheduled evidence stages and four memory checkpoints. Never claim a method performed 36 research actions if it stopped after 5, nor call externally scheduled memory probes spontaneous autonomous research. If a pilot demonstrates negligible sustained work or context pressure, do not run the main study under misleading labels: redesign objectively, document and refreeze before any main outcomes are seen.

## 6. Required deliverables / acceptance criteria

1. Versioned manifests for S/L/M (with hidden gold keys separate from agent prompts); task-construction audit, deterministic real-citation reachability proofs and disjoint pilot lists.
2. Validated graph visibility in actual final model input; proof of CLM graph-context edit/preservation/recovery without hidden information or larger budget.
3. Stage-aware runner that preserves agent state between L phases, prevents entire-task early STOP from skipping phases, records premature STOP as an outcome, and respects safety refusal and hard ceilings.
4. Capacity-aware 96-paper stream runner that ensures actual evidence delivery, snapshots without contamination, deterministic Branch A/B probes at four checkpoints, and strictly limited recovery.
5. Shared provider settings for four hosted arms, atomic checkpoint/receipt/accounting protocol, global budget authorization, no ambiguous-request retries, and controllable execution time limit.
6. Read-only dashboard tabs for S/L/M, per-architecture performance and failures, meaningful actions by phase, 24/48/72/96 memory curves, graph edge delivery, memory edits, tokens/latency/cost and distinct task counts.
7. Paper-ready separate LaTeX tables and figures, task-level paired contrasts, confidence intervals, uncertainty/failure notes, raw cell/result lineage; no inflated held-out or hallucination claims.
